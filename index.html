    Send to Xteink

    Did the books arrive on the reader?

    Recommended. The reader joins your Wi-Fi on its own, your phone stays online, and one tap sends every waiting book.

    Each time

    1. On the reader, open File Transfer → Join a Network.

      It reconnects to your saved Wi-Fi by itself. No QR codes.

    2. Tap “Send waiting books” above.

      Your phone downloads each book, saves it to your folder and uploads it to the reader.

    One-time setup
    1. Save your Wi-Fi on the reader.

      Settings → System → Wi-Fi Networks → add your home network. It must be 2.4 GHz; most home routers offer this.

    2. Create the “Send to Xteink” shortcut

      Open the Shortcuts app, tap +, name it exactly Send to Xteink and add these actions in order:

      1. Get Dictionary from Shortcut Input
      2. Get Dictionary Value for key mkdir → Get Contents of URL: method POST, Request Body “Form”, fields name = Books and path = /
      3. Get Dictionary Value for key books in Dictionary → Repeat with Each item:
        1. Get Dictionary Value url from Repeat Item → Get Contents of URL
        2. Set Name of Contents of URL to Dictionary Value name from Repeat Item
        3. Save File to your Xteink folder (turn off “Ask Where to Save”)
        4. Get Dictionary Value upload from Dictionary → Get Contents of URL: method POST, Request Body “Form”, add a File field named file = Renamed Item
      4. Show Notification “Books sent to Xteink”
    3. Test it.

      Put the reader in Join a Network, then tap Send on any book in your Library.

    Works anywhere, without your home Wi-Fi. Your phone loses internet while it's connected to the reader.

    1. Download your books first,

      while you still have internet.

    2. On the reader, open File Transfer → Create Hotspot.
    3. On your phone, open Settings → Wi-Fi and tap CrossPoint-Reader.

      No QR code needed. After the first time your phone remembers the network.

    4. Open the reader's upload page and pick the books from your folder.
      Open upload page
    5. Mark them as sent in your Library,

      then rejoin your normal Wi-Fi.

    Skip the phone entirely

    The reader can browse and download Project Gutenberg's free catalog on its own. On the reader, go to Settings → System → OPDS Servers → Add Server and enter:

    https://m.gutenberg.org/ebooks.opds/

    Typing on the reader is slow, so you can add it from http://crosspoint.local/settings instead while the reader is in File Transfer.

    Reader settings

    If crosspoint.local doesn't work, use the IP address the reader shows in Join a Network, for example 192.168.1.102.

    Keep your books in one folder

    On iPhone, go to Settings → Apps → Safari → Downloads and choose a folder such as “Xteink” in Files. Books you download here land there.
